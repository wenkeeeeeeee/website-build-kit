# Reference library

References come only from the Benchmarks below, or Awwwards when it fits the business better (step 3 of
`research.md`). Open an entry before picking it: these notes don't prove it suits the client. No client names or
client-site links here. Wrap-up adds to Benchmarks and "Rejected" as `build.md` says.

## Benchmarks
The level to look for; each counts as a reference when it fits the client's business, tone and hero material.
**Tone:** playful for Lando Norris, Don't Board Me and Partake; luxury for Cartier, Gentle Monster and TAG Heuer; modern
and professional for the rest. **Made of** is what the hero is built from: a 3D Benchmark can lead only a hero you will
really build in 3D or code. Take the craft, not the subject.

## Component sources
- https://reactbits.dev/ : animated text, backgrounds and small components. Fetch the source with
  `tools/web/reactbits.cjs` and port it to plain JS.
- https://ui.aceternity.com/ : hero effects, cards and scroll components.
- https://21st.dev/ : community library of React and Tailwind components (heroes, buttons, cards, text effects,
  backgrounds, shaders). Search it by section type and copy the code from the component page. Each component has its
  own author and license, so check it before use. Port the one you pick to plain JS and CSS, and restyle it for the
  client.
