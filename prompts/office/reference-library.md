# Reference library

Use this for leads, and open an entry before picking it: these notes are not proof it suits the client. **Result** is how the work built from it landed: `liked`, `mixed`, `rejected`, or `untested` when
there was no clear feedback. Never add client names or links to client sites here. When a job wraps up, update the
Result column and promote anything from "To try".
